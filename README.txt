**Requirements**
Πριν από οποιαδήποτε άλλη ενέργεια, ο χρήστης θα πρέπει να εγκαταστήσει τις βιβλιοθήκες που περιέχονται στο αρχείο requirements.txt (π.χ. θα μπορούσε να τοποθετήσει το αρχείο txt στον φάκελο Source_Code και έπειτα να χρησιμοποιήσει την εντολή "pip install -r requirements.txt" στο terminal) 
(Σημείωση: Προτείνεται να χρησιμοποιείται η έκδοση 3.10 της Python)


-Training: Για την εκπαίδευση ενός νέου μοντέλου, ο χρήστης θα πρέπει να ανοίξει το φάκελο Source Code σε έναν editor της αρεσκείας του. Εκεί θα μπορεί να χρησιμοποιήσει το αρχείο main_sac.py, να θέσει το όνομα του περιβάλλοντος το οποίο θα θέλει να εκπαιδεύσει (εφόσον αυτό υποστηρίζεται από τις βιβλιοθήκες Gymnasium και Mujoco) και να το τρέξει. Επιπλέον του παρέχονται τρία αρχεία τα οποία υλοποιούν ήδη την εκπαίδευση τριών περιβαλλόντων: InvertedPendulum-v4, HalfCheetah-v4 και Hopper-v5.

-Testing: Εφόσον έχει ολοκληρωθεί η εκπαίδευση του μοντέλου του χρήστη, θέτοντας την μεταβλητή load_checkpoint = True και εκτελώντας τον ίδιο κώδικα, φορτώνονται τα αποθηκευμένα μοντέλα από το path του chkpt_dir και εμφανίζεται το render παράθυρο, οπτικοποιώντας την αλληλεπίδραση του εκπαιδευμένου agent με το περιβαλλόν.
